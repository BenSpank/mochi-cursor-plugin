# mochi-bug-report

Find the call: ask, or search `query_mochi_meetings` for the most recent one about the problem. Read it with `get_meetings`; for booked calls, `get_meeting_transcript` gives the reporter's own words.

Write a ticket ready to paste into GitHub Issues or Linear:
- What goes wrong, in the reporter's words where you have them
- Steps to reproduce
- What should happen instead
- Where: browser, device, account, page
- Who reported it, and the meeting and date

Mark anything you inferred rather than read, and say when you're paraphrasing because the note has no transcript.
